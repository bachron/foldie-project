# Foldie Project

A folding-bike build project. Scope: folding bikes in general — Brompton lines first, other brands welcome.
Each build has its own plan and parts tracker. Child seats and their mounts are excluded from planning weights in every build.

| Build | Base | Status | Files |
|---|---|---|---|
| **HEXATI T20** (separate from the Brompton G Line build below) | HEXATI T20 titanium tri-fold, 20" wheels, Brompton G Line geometry | Parts being decided and ordered | `T20_Build_Plan.md`, `T20_Build_Options.md` |
| **Black Lacquer Superlight** (C Line / pre-C Line) | Used Brompton donor, 16" wheels, rebuilt around a Ti stem, fork and Ti rear triangle | Research | `C_Line_*` (added once research lands) |

| **Brompton G Line (Upgraded, bought used)** | Used G Line size S from Carousell: Juin hydraulic brakes, SRAM Force AXS 1x12, SMC carbon wheels; converting to size M | In progress (bought 18 Nov 2026; choosing parts to swap) | `G_Line_Build_Plan.md`, `G_Line_Upgraded_Build.md`, `G_Line_Current_Parts_List.md` |
| **Aceoffix C5 / T1** | Aceoffix C5 (sold as T1 by some resellers), 16" aluminium tri-fold, carbon fork | New plan | `Aceoffix_C5_T1_Build_Plan.md` |

Handoffs live in `docs/handoffs/`.

> The GitHub repo and folder are named `foldie-project` (renamed from `t20-g-line` on 2026-10-24).
