# Foldie Project

A folding-bike build project. Scope: folding bikes in general — Brompton lines first, other brands welcome.
Each build has its own plan and parts tracker. Child seats and their mounts are excluded from planning weights in every build.

| Build | Base | Status | Files |
|---|---|---|---|
| **T20 / G Line** | HEXATI T20 titanium tri-fold, 20" wheels, Brompton G Line geometry | Parts being decided and ordered | `T20_Build_Plan.md`, `T20_Build_Options.md` |
| **Black Lacquer Superlight** (C Line / pre-C Line) | Used Brompton donor, 16" wheels, rebuilt around a Ti stem, fork and Ti rear triangle | Research | `C_Line_*` (added once research lands) |

Handoffs live in `docs/handoffs/`.

> The GitHub repo and folder are still named `t20-g-line`; only the project name changed.
