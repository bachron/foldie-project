# Foldie Project: seatpost and saddle candidates, G Line and C Line / P Line

**Date:** 20 Nov 2026. **Prices:** Carousell Singapore asking prices (search results, listings not opened) unless stated; US$ at roughly 1 = S$1.3. Weights are seller or retailer claims unless stated, not weighed.
**Fit:** a standard Brompton post is 31.8 mm class (Brompton lists its carbon post at 31.66 mm) and Brompton lists the same post as fitting A, C Mk5/Mk6, P Mk1/Mk2, T and G Line. So one post type serves both bikes. C Line and P Line share the same length. The G Line is size S today (standard length); the planned M conversion needs a longer, extended-length post.
**Saddle clamp:** Brompton Pentaclip takes 7 mm round rails. Carbon-rail saddles need an adapter (Ti Parts Workshop sells one) or a carbon-rail clamp. Not verified per saddle.

> **Conflict to settle:** `C_Line_Build_Plan.md` excludes carbon seatposts because a rear child seat would clamp to the post (owner rule, T20 and C Line notes). If either bike will carry that seat, take an alloy or Ti post from the table instead. Carbon posts also have low rider-weight limits (WOOdman lists 110 kg).
> **G Line note:** the G Line already has a Hexagon Ti post (about 170-240 g, estimated, unweighed). Every carbon post below is 204-310 g, so for the S bike a carbon post saves little or nothing. The reason to buy one is the M conversion, which needs a longer post anyway.
